🚀 Project Overview

This project is an AI Customer Support Agent designed to assist customers of a beverage brand (Kokum Soft Drinks).
The agent can respond to customer questions related to products, availability, pricing, orders, and general brand information — reducing manual support effort.

Built using Jotform AI tools, this project demonstrates how AI can be quickly deployed to solve real-world business problems without a traditional backend.
